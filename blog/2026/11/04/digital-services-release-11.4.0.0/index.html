Digital Services Release 11.4.0.0

Annotated release notes. Full changelog on GitHub
Wednesday, November 04, 2026

By role: Content Editors · Site Builders · Developers · Decision Makers

Full Changelog: https://github.com/YCloudYUSA/yusaopeny/compare/11.3.1.6...11.4.0.0

Summary

YMCA Website Services 11.4 moves the distribution to Drupal 11.4. These notes cover the changes from 11.3.1.6 up to 11.4.0.0. The current build is 11.4.0.0-rc5 (tagged 2026-11-04):

  • Drupal Core 11.3.13 → 11.4.11 — 204 packages changed in a test upgrade (measured on 11.4.0.0-rc4)
  • Security — a fresh composer update resolves current releases of core, webform, captcha, paragraphs, blazy, rabbit_hole, svg-sanitize, guzzle and symfony packages; the Security section lists the advisories and the constraint changes
  • GroupEx Pro removed from the distribution — drupal/groupexpro is no longer in the codebase; the Embedded GroupEx Pro Schedule continues as its own package ( SA-CONTRIB-2026-278 affects groupexpro before 2.2.1)
  • Activity Finder 7.2 — Vue 3, Category Tags filter, “Filters on Top” layout, location and schedule fixes
  • jQuery Migrate self-hosted — no more code.jquery.com request on every page (removes a load-order race behind jQuery is not defined errors)
  • Alt text on the Small Y demo images
  • Drupal 12 compatibility declared — Layout Builder blocks, themes and content types got releases that declare ^12 (e.g. lb_cards 3.1.0, y_camp 3.1.0, ws_event 2.1.0)

GroupEx Pro removed from the distribution

The Drupal Security Team marked the drupal.org project groupexpro unsupported on 2026-10-28. SA-CONTRIB-2026-278 (Critical, PHP object injection, affects versions before 2.2.1) was published on 2026-11-04. The project was restored the same day with the fix in 2.2.1. The distribution removed drupal/groupexpro in 11.4.0.0-rc4 ( #393). It is not a direct requirement in composer.json.

  • drupal/groupexpro, its drupal/openy_gxp package and drupal/openy_pef_gxp_sync are removed from the distribution ( #393).
  • The Embedded GroupEx Pro Schedule (the paragraph that embeds the GroupEx schedule widget) keeps working: the module moved to ycloudyusa/embedded_groupexpro_schedule 1.0.0 with the same module name. The account id is stored and output as a number. embedded_groupexpro_schedule_update_10001 sets a stored id that is not a number to 0, so enter the account id again after drush updb. The widget scripts load over https only.
  • openy_gxp, openy_group_schedules, groupex_form_cache and openy_pef_gxp_sync come as self-uninstalling stubs from ycloudyusa/useless_machines 2.2.0 ( useless_machines#15, #394): drush updb drops any remaining GroupEx Form Cache / GXP mapping data and tables, then uninstalls them.

Activity Finder 7.2

  • Vue 3 for Activity Finder 4 and the Group Schedules dashboard (openy_repeat 4.x), loaded from the shared openy_system/vue3 library (openy_custom 3.2+) ( #384).
  • Category Tags — new filter mode in the AF4 block, Solr facet, wizard step and sidebar; needs openy_node_session 2.4 (Category Tags vocabulary and session field) ( AF#85, openy_node_session!5, #390).
  • Filters on Top layout style for the Activity Finder block.
  • Fixes: “Limit by Location” dropdown no longer empty; location limits work as a constraint on the selection; date-only sessions no longer show 6:00pm-6:00pm; results load when the page URL contains credentials.
  • Backend is now a plugin (solr / mock); openy_activity_finder_update_9006 converts the setting and enables the Solr submodule only on sites that have search_api_solr ( AF#86).

jQuery Migrate self-hosted

The profile used to inject jquery-migrate-4.0.0-beta.1.js from code.jquery.com into core’s jQuery library. Under load it raced ahead of jQuery (Uncaught ReferenceError: jQuery is not defined). Now jQuery Migrate 4.0.2 ships with the profile as openy/jquery_migrate with a dependency on core/jquery ( #386).

Layout Builder Tables

drupal/lb_table 1.1.1+ (required by y_lb 5.2.1): tables without a <thead> are no longer turned into tablesaw tables, so one header-less table no longer breaks the other tables on the page ( lb_table!16, y_lb#317).

Small Y demo images: alt text

The Small Y demo images get alt text on new installs; existing sites get it from ws_small_y_update_91009 after drush updb (only where alt is empty) — ws_small_y 2.2.0 ( !85, !86).

Font Your Face patch

drupal/fontyourface 4.3.0 moved its page_attachments hook into a hook class that runs last. The provider submodules (local_fonts, google_fonts_api and others) run before it, find no fonts, and no font stylesheet is attached. The distribution patches drupal/fontyourface with the upstream merge request !20 for the open issue #3630630 ( #398, 11.4.0.0-rc5).

  • Sites that use y_fonts are not affected: it has its own page_attachments hook and no fontyourface dependency.
  • If your root composer.json carries its own patch for #3630630, remove it.

Webform UI enabled with the Webform block

drupal/lb_webform 2.1.1 requires webform_ui, so the Webform UI is on wherever the Layout Builder Webform block is; existing sites get it from lb_webform_update_10001 ( lb_webform!14).

Cleanup

  • Stale composer patches dropped; the rabbit_hole patch that downloaded as an empty diff is fixed; direct guzzlehttp/guzzle require removed (Guzzle is still installed because Drupal core requires guzzlehttp/guzzle: ^7.10) ( #387).
  • CKEditor 4 library plugins removed: library-ckeditor/font, colorbutton, panelbutton — CKEditor 5 only ( #374).
  • Minimums raised: openy_carnation ^4.2 ( #389), openy_features ^5.2, y_lb ^5.1, confi ^4.2, upgrade_tool ^4.2, useless_machines ^2.2.0.

Migration Guide

Composer: allow symfony/runtime

Drupal 11.4 core pulls symfony/runtime, whose Composer plugin is blocked unless the site allows it (root-only config):

"config": { "allow-plugins": { "symfony/runtime": true } }

GroupEx Pro

  • Sites that use the Embedded GroupEx Pro Schedule paragraph: the module keeps its name; updb converts a stored account id to a number (embedded_groupexpro_schedule_update_10001). A stored id that is not a number becomes 0: enter the account id again at /admin/openy/integrations/groupex-pro/groupexpro.
  • Remove any root require of drupal/groupexpro, drupal/openy_gxp or drupal/openy_pef_gxp_sync: useless_machines 2.2.0 conflicts with them.
  • openy_prgf_group_schedules (openy_features) depends on openy_group_schedules; where it is still enabled, the stub uninstalls it together with itself.

Activity Finder

  • Sites with Solr keep the Solr backend (submodule enabled by openy_activity_finder_update_9006).
  • Sites on the Solr backend without search_api_solr are switched to the mock backend.
  • Category Tags are opt-in per block: Activity Finder block → Location & Category filters → Category filters → Category Tag. The default stays Activity (Program Subcategory).
  • Sites that run their own fork of Activity Finder or openy_node_session as a path repository must drop it and move to the released packages.

Group Schedules (openy_repeat 4)

The distribution requires drupal/openy_repeat ^4.0.0. Remove a root require of drupal/openy_repeat: ^3.x, or the update does not resolve.

CKEditor 4 plugins

If a custom module still references library-ckeditor/*, remove it; font family/size and colours come from ckeditor5_plugin_pack_font.

Upgrade Path

From 11.3.1.x or an 11.4.0.0 release candidate:

composer config allow-plugins.symfony/runtime true
composer require ycloudyusa/yusaopeny:^11.4@RC --no-update
composer update -W
drush updb -y --no-cache-clear
drush cr

Keep @RC while 11.4.0.0 is a release candidate; drop it after the stable release.

composer require without --no-update (or -W) fails on an 11.3 site — the locked dependencies (e.g. drupal/confi 4.1) block a partial update — and composer reverts composer.json.

All migrations run in drush updb: 34 updates on a fresh extended 11.3.1.5 install upgraded to 11.4.0.0-rc4 (measured on rc4, not re-run on rc5; sites with more modules run more), among them the blazy→image display updates, the Activity Finder 6.2.1 → 7.2.1 backend conversion (openy_activity_finder_update_9006), metatag 403/404 defaults, rabbit_hole and Trash storage updates, lb_webform_update_10001; on sites that use them also the GroupEx Pro stub clean-up and uninstall, the embed account conversion and ws_small_y_update_91009.
